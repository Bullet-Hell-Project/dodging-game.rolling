# Dodging Game

A tiny browser bullet-hell. Dodge white bullets, chip down the green boss, survive.

Play it now: https://bullet-hell-project.github.io/dodging-game.rolling/

![status](https://img.shields.io/badge/status-rolling-brightgreen) ![license](https://img.shields.io/badge/license-MIT-blue) ![deps](https://img.shields.io/badge/dependencies-none-orange)

Single-file HTML. Vanilla JS. No build step. WASD to move, R to restart.
